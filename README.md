
# Molt — Fotografia por outro ângulo

Repositório oficial das páginas institucionais do aplicativo **Molt**, desenvolvido para dispositivos iOS e publicado por meio do GitHub Pages.

## Sobre o Molt

O Molt propõe uma nova experiência fotográfica, valorizando a criatividade e a personalidade de cada registro.

O aplicativo utiliza recursos nativos do iPhone para fotografar e armazenar imagens localmente na biblioteca de fotos do dispositivo.

## Privacidade

O Molt não coleta dados pessoais nem armazena fotografias em servidores próprios ou serviços externos.

As imagens capturadas são armazenadas localmente na biblioteca de fotos do dispositivo.

## Créditos e licenças

O aplicativo utiliza efeitos sonoros provenientes do Freesound e do Pixabay, além de fontes tipográficas disponibilizadas pelo Google Fonts.

As respectivas autorias, atribuições e licenças estão disponíveis na página oficial de créditos e no [documento de créditos e licenças](./CREDITOS-E-LICENCAS-MOLT.md).
