# Molt — Política de Privacidade

Repositório dedicado à publicação da Política de Privacidade do aplicativo **Molt**, disponível para dispositivos iOS.

**Molt — Fotografia por outro ângulo.**

O aplicativo utiliza recursos nativos do iPhone para fotografar e armazenar imagens localmente na biblioteca de fotos do dispositivo.

## Privacidade

O Molt não coleta dados pessoais nem armazena fotografias em servidores próprios ou serviços externos.

A política de privacidade completa está disponível no site publicado por meio do GitHub Pages.

## Contato

Para dúvidas sobre o aplicativo ou sua política de privacidade, entre em contato pelo e-mail oficial de suporte do Molt.
